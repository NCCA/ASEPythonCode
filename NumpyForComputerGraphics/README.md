# NumPy for Computer Graphics

These are the NumPy operations I use in the graphics lectures and labs, worked through as seven marimo lessons and a solutions notebook.

| Notebook                                                      | Covers                                                                                     | Examples behind the lesson                                                                                                                                      |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [1: arrays and vertex data](NumPyForCGPart1Arrays.py)         | dtype, byte sizes, sampling, ufuncs, structured records, casting                           | [FirstTriangles](../GraphicsDemos/FirstTriangles/WebGPU/WebGPUTriangle.py), [TriangleGrid](../GraphicsDemos/TriangleGrid/WebGPU/WebGPUTriangleGrid.py)          |
| [2: shapes, views and grids](NumPyForCGPart2Shapes.py)        | reshape, views, array combinations, broadcasting, meshgrid, strides, connectivity          | [TriangleGrid](../GraphicsDemos/TriangleGrid/WebGPU/WebGPUTriangleGrid.py)                                                                                      |
| [3: transformations](NumPyForCGPart3Transforms.py)            | matrix products, homogeneous points, order, tolerances, perspective division, matrix bytes | [Points](../GraphicsDemos/Points/OpenGL/OpenGLPoints.py), [IntroductionToNumpy](../Lecture5/IntroductionToNumpy.py)                                             |
| [4: images and colour](NumPyForCGPart4Images.py)              | RGBA axes, masks, where, byte overflow, alpha, packed pixels                               | [Image](../Lab4/Image/src/image/Image.py), [ImageUint32](../Lab4/Image/src/image/ImageUint32.py), [BlitMT](../Lab5/BlitMT.py)                                   |
| [5: random points and particles](NumPyForCGPart5Particles.py) | seeded generators, sphere sampling, reductions, axes, Euler integration, masks, bounds     | [Points](../GraphicsDemos/Points/OpenGL/OpenGLPoints.py), [Emitter](../Lab6/Particle/Emitter.py)                                                                |
| [6: a lit mesh](NumPyForCGPart6Mesh.py)                       | deformation, winding, normals, inverse transpose, diffuse light, UVs                       | [UpdateMesh](../GraphicsDemos/UpdateMesh/WebGPU/WebGPUTriangleGridWireFrame.py), [FlatShaded](../GraphicsDemos/FlatShaded/WebGPU/PhongShaderWithWireFrame.wgsl) |
| [7: an interactive WebGPU mesh](NumPyForCGPart7WebGPU.py)     | vertex layouts, WGSL, depth, browser rendering, mouse camera controls                      | [MarimoDemos/WebGPU](https://github.com/NCCA/MarimoDemos/tree/main/WebGPU)                                                                                      |

[Exercise solutions](NumPyForCGSolutions.py) contains runnable answers to all 36 exercises, numbered to match the lessons. It generates its own data and includes optional WebGPU checks.
